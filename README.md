## 🚀 Sobre mim

Olá! Me chamo **Iuker**, tenho **21 anos** e moro em **Curitiba, PR**.

Transformo dados do SAP S/4HANA em informação que a área de negócio realmente usa.

Atuo na ponta a ponta do analytics SAP: modelagem de dados no back-end (**CDS Views / VDM**), camadas no **Datasphere** e consumo em **SAP Analytics Cloud** — dashboards, relatórios e modelos de planejamento.

Meu foco é conectar regra de negócio com modelagem técnica, para que o dado seja confiável, performático e reutilizável em BI e Planning.

```text
🔗  S/4HANA (CDS)  →  Datasphere  →  SAC (BI + Planning)
```

## 🛠️ O que eu faço

Construo a cadeia analítica do SAP — do banco ao dashboard — com visão de negócio e de dados:

☁️ **SAP Datasphere**  
Modelagem de dados na nuvem, views, associações e integração com o S/4HANA, preparando a camada semântica para consumo analítico.

📊 **SAP Analytics Cloud (BI & Planning)**  
Stories, dashboards e modelos de planejamento. Data Actions / Advanced Formulas para forecast, saldo acumulado, budget → forecast e planejado × realizado.

⚙️ **ABAP & CDS Views**  
Views de interface e consumo (`ZI_` / `ZC_`) no S/4HANA para analytics financeiro, comercial e de custos — base limpa e reutilizável para Datasphere e SAC.

🗄️ **SQL · HANA**  
Consultas, transformação e ajuste de performance para garantir integridade e velocidade nas análises.

📈 **Domínios que atendo**  
Analytics FI/CO (DRE, Balanço, Fluxo de Caixa, Contas a Pagar/Receber), SD (vendas × faturamento, margem) e apoio à decisão com relatórios acionáveis.
